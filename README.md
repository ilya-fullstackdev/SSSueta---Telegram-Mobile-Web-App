# Sssueta Club

Telegram Mini App — карточка профиля клуба с балансом, мероприятиями и внутренней валютой. Работает поверх Telegram WebApp API и Firebase (Firestore) в качестве бэкенда.

## Возможности

- 👤 **Профиль пользователя** — имя, аватар и дата регистрации подтягиваются из Telegram, персональный код клуба генерируется и хранится в Firestore.
- 🎟 **Мероприятия** — список событий из Firestore с датой, адресом (со ссылкой на Google Maps) и ценой; купленные билеты помечаются автоматически.
- 💳 **Кошелёк** — баланс внутренней валюты, калькулятор конвертации и кастомная цифровая клавиатура для ввода сумм.
- 📋 **Копирование адреса** — быстрое копирование адреса мероприятия в буфер обмена с уведомлением.
- 📱 **Адаптивная вёрстка** — интерфейс подстраивается под мобильные экраны (viewport-относительные единицы).

## Стек

- Чистый HTML / CSS / JavaScript (без сборщиков и фреймворков)
- [Telegram WebApp API](https://core.telegram.org/bots/webapps)
- [Firebase Firestore](https://firebase.google.com/docs/firestore) (compat SDK)

## Запуск локально

1. Клонируйте репозиторий.
2. Замените конфигурацию Firebase в [`js/firebase.js`](js/firebase.js) на свою (если нужен собственный проект).
3. Запустите любой статический сервер в корне проекта, например:

   ```bash
   npx serve .
   ```

4. Откройте приложение как Telegram Mini App через [BotFather](https://core.telegram.org/bots/webapps#testing-mini-apps) — вне Telegram интерфейс отображается в гостевом режиме (без баланса и кода).
